# Downloading U.S. County- and City-Level Population Data for Linking to Environmental Datasets

## TL;DR
- **For exact counts, use the Decennial Census (table P1 / B01003 lineage); for annual official totals between censuses, use the Population Estimates Program (PEP); for detailed characteristics of small cities, use the ACS 5-year estimates.** All three are downloadable as CSV from data.census.gov and the Census API, and all carry FIPS/GEOID codes that join directly to TIGER/Line geographies and to environmental data keyed on county FIPS.
- **The cleanest join path is the FIPS/GEOID code:** a 2-digit state + 3-digit county FIPS (5-digit county GEOID) links population to USGS fertilizer/manure estimates, USDA NASS Census of Agriculture, and CDC data; cities ("places") use a 2-digit state + 5-digit place FIPS (7-digit place GEOID).
- **Watershed-based environmental data (USGS NWIS water quality, EPA ATTAINS) is organized by HUC, not county**, so joining population requires aggregating monitoring sites to county or building an area-weighted county↔HUC12 crosswalk — this is the single biggest methodological caveat.

## Key Findings

### The three Census Bureau population products and when to use each
The Census Bureau itself gives explicit guidance: use the **Decennial Census** for actual population counts and basic characteristics; use the **Population Estimates Program (PEP)** for annual totals in the years between censuses; and use the **American Community Survey (ACS)** for characteristic distributions (percentages, medians, rates) rather than totals. ACS estimates are statistically controlled to match PEP totals.

- **Decennial Census** (every 10 years, reference date April 1): a complete enumeration giving the official count. County and place data are downloadable at data.census.gov (e.g., 2020 table P1, DEC Demographic and Housing Characteristics; table P9 for race/ethnicity). Note that 2020 data carry "differential privacy" noise at small geographies (no noise was added to state apportionment counts).
- **Population Estimates Program (PEP)** (annual, reference date July 1): the official source for population totals for the nation, states, counties, **cities and towns**, plus housing-unit estimates. Released in annual "vintages"; the latest vintage supersedes all prior years in its time series, and data from different vintages should not be combined.
- **American Community Survey (ACS)**: 1-year estimates (geographies ≥65,000 population), 1-year Supplemental (≥20,000), and 5-year estimates (all geographies including all counties, places, and tracts). All ACS values are estimates with a published margin of error (MOE). Use 5-year for small cities/counties. (The 3-year ACS was discontinued after the 2011–2013 release.)

### How to download from Census sources (formats and tools)
1. **data.census.gov** — interactive web tool; tables download in CSV, XLSX, and PDF. Total Population is ACS table **B01003** (variable **B01003_001E**); the Decennial count is the P1 table.
2. **Census Data API** (`api.census.gov`) — programmatic queries returning JSON. Example for all cities (places) in California (state 06), ACS 5-year: `https://api.census.gov/data/2022/acs/acs5?get=NAME,B01003_001E&for=place:*&in=state:06`. An API key is required for all queries, free at `https://api.census.gov/data/key_signup.html`. PEP current vintages are no longer served via the API; older vintages (2019 and earlier) remain on it.
3. **PEP bulk CSV files** — County totals: "County Population Totals and Components of Change: 2020–2025," file **CO-EST2025-ALLDATA** (landing page `census.gov/data/tables/time-series/demo/popest/2020s-counties-total.html`). City/town totals: the **SUB-EST** file. For Vintage 2024 the direct file is `https://www2.census.gov/programs-surveys/popest/datasets/2020-2024/cities/totals/sub-est2024.csv` (dataset code SUB-EST2024; columns include SUMLEV, STATE, COUNTY, PLACE, COUSUB, NAME, STNAME, and POPESTIMATE2020–2024). Filter SUMLEV = 162 for incorporated places. A Vintage 2025 equivalent exists at the `2020-2025/cities/totals/sub-est2025.csv` path.
4. **TIGER/Line shapefiles** — the geometry (no demographics) for joining. Base path `https://www2.census.gov/geo/tiger/TIGER2024/`, with `COUNTY/` (national file `tl_2024_us_county.zip`) and `PLACE/` (per-state `tl_2024_SS_place.zip`, where SS = state FIPS) layers. Simplified **Cartographic Boundary Files** (`cb_…`, e.g. `cb_2023_us_county_500k.zip`) are a separate generalized option for mapping, under `https://www2.census.gov/geo/tiger/GENZ2023/shp/`. An interactive picker is at `https://www.census.gov/cgi-bin/geo/shapefiles/index.php`. As the Census notes, TIGER files "do not include demographic data, but they do contain geographic entity codes that can be linked to the Census Bureau's demographic data, available on data.census.gov."

### Joining population to other datasets via FIPS/GEOID
FIPS codes build left-to-right from general to specific: state = 2 digits (Illinois = 17); county adds 3 digits (Cook County = 17031); place/city adds a 5-digit place code. The Census Bureau's GEOID concatenates these. A key gotcha: data.census.gov tables carry a fully-qualified GEOID (e.g., `0500000US17031`) in a field called GEO_ID, while TIGER shapefiles carry the bare GEOID (`17031`) — strip everything up to and including the "US" to match them. Preserve leading zeros (treat FIPS as strings, not numbers). To join in GIS, join the table's GEO_ID to the shapefile's GEOID/GEOIDFQ field.

### Other government/institutional sources at county or municipality level
- **USGS county-level nitrogen & phosphorus from fertilizer and manure, 1950–2017** (Falcone, J.A., 2021, *Estimates of county-level nitrogen and phosphorus from fertilizer and manure from 1950 through 2017 in the conterminous United States:* U.S. Geological Survey Open-File Report 2020–1153, 20 p.; data release DOI 10.5066/P9VSQN3C; ScienceBase item `https://www.sciencebase.gov/catalog/item/5ebad56382ce25b51361806a`). Already keyed to county FIPS — a near-perfect join partner for population. Data come as `.xlsx` workbooks (`N-P_from_fertilizer_1950-2017…xlsx`, `N-P_from_manure_1950-2017…xlsx`) plus per-year `.txt` tables and a `model_archive.zip`. Earlier county-level series exist (Gronberg/Spahr & Brakebill/Gronberg, 1987–2012, DOI 10.5066/F7H41PKX; Alexander/Smith, 1945–1985, OFR 90-130).
- **USGS NWIS / Water Quality Portal (WQP)** — water quality data queryable by state and county FIPS (`statecode`, `county_cd`) via REST web services returning CSV/Excel/TSV; also by HUC. WQP is jointly run by USGS, EPA, and the National Water Quality Monitoring Council and serves 430M+ result records. Note USGS Water Data for the Nation is mid-migration (NWISWeb being decommissioned in favor of the modernized WDFN platform and new API).
- **EPA** — ATTAINS (Clean Water Act §303(d)/§305(b) assessments), How's My Waterway, and WATERS Geospatial Data Downloads (geodatabases + ESRI/OGC services); organized primarily by HUC/waterbody, not county.
- **USDA NASS Quick Stats** — Census of Agriculture (every 5 years, ending in 2 and 7) and surveys, with state- and county-level data; downloadable via web tool, bulk gzipped FTP files, or API (`https://quickstats.nass.usda.gov/api`, formats JSON/CSV/XML, key required). This is the source for county fertilizer expenditures and crop/livestock data underlying the USGS estimates.
- **USDA ERS** — Atlas of Rural and Small-Town America and County-Level Data Sets: pre-packaged county CSV/Excel combining Census population (Decennial, PEP, ACS) with poverty, employment, education; each row keyed by county FIPS.
- **CDC WONDER** — Bridged-Race Population Estimates by year, county, race, age, and sex (1990–2020); designed for computing vital rates. NCHS has discontinued the bridged-race series going forward (ending with the 2010–2020 intercensal release).
- **Census SAIPE** — model-based annual county income and poverty estimates (and poverty universe), via API (`api.census.gov/data/timeseries/poverty/saipe`) and bulk text files; the best single-year county estimates of poverty/median income, with lower variance than ACS for small counties.
- **NHGIS (IPUMS)** — the best source for **long-run historical time series**: county and state population back to 1790, standardized geographic crosswalks, GIS boundary files, plus historical agricultural census data. Free with registration; API and R/Python access.

### Time-series availability for longitudinal analysis
- **PEP**: annual county and city totals within each decade (e.g., 2020–2025), but each vintage re-estimates the whole series; series should not be chained across decades without using the official intercensal estimates (e.g., the 2010–2020 Intercensals released Nov 2024).
- **Decennial**: every 10 years (county-level back to 1790).
- **ACS 5-year**: rolling annual releases from 2005–2009 onward; non-overlapping periods should be used for trend comparison.
- **CDC WONDER bridged-race**: 1990–2020 annual.
- **USGS fertilizer/manure**: ~5-year intervals coinciding with Ag Census years, 1950–2017.
- **NHGIS**: the deepest historical archive with standardized, boundary-consistent time series.

## Details

### Decennial vs. ACS vs. PEP — the critical distinction for a researcher
This matters because the three products give *different population numbers for the same county in the same year*, each "correct" for a different purpose:
- The **Decennial Census** is a constitutionally mandated complete count (April 1). It is the gold-standard denominator but updates only every decade and (since 2020) injects privacy noise at small geographies.
- **PEP** carries the count forward annually using births, deaths, and migration. It is the *official* between-census total and is what ACS estimates are controlled to. Use PEP when you need a consistent annual population denominator to normalize environmental loads (e.g., kg N per capita per county per year).
- **ACS** is a rolling sample survey. Its strength is characteristics (age, income, housing), not totals; every estimate has an MOE that, for small areas, can rival the estimate itself. For places under 65,000 (the vast majority of U.S. municipalities), only the **5-year** ACS is available, and the reported "population" is a period estimate, not a point-in-time count.

### Geography: what counts as a "city/municipality" in Census data
The Census Bureau's unit for a city is a **"place."** Places are either **incorporated places** (legally bounded cities, towns, villages, boroughs) or **Census Designated Places (CDPs)** (statistical equivalents for unincorporated communities, with no legal boundary or government). The scale is large: per the Census Bureau's Vintage 2024 city/town estimates (released May 15, 2025), there were **19,479 incorporated places**, of which 75 percent — 14,603 cities — had populations under 5,000. Important wrinkles: in New England, New York, Wisconsin, New Jersey, Pennsylvania, and some other states, "towns"/"townships" are **Minor Civil Divisions (MCDs)**, a separate geography from places; Hawaii has no incorporated places (all are CDPs); and Puerto Rico's "municipios" are treated as county-equivalents. Place boundaries change over time (annexation), so place-level time series are less boundary-stable than counties. The PEP SUB-EST file and ACS both provide place-level data; for MCD-heavy states, decide deliberately whether you want places or county subdivisions.

### The watershed problem and the county↔HUC crosswalk
Most water-quality and runoff data are organized by **Hydrologic Unit Code (HUC)** — a nested system in the USGS National Watershed Boundary Dataset (WBD). Per USGS, the hierarchy comprises **21 regions (HUC2), 222 subregions (HUC4), 370 basins (HUC6), ~2,270 subbasins (HUC8), ~20,000 watersheds (HUC10), and ~87,020 HUC12 subwatersheds** for the conterminous U.S. (USGS Science Data Catalog item 63d31e73d34e06fef1501265 describes "a shapefile with 87,020 12-digit hydrologic unit codes (HUC12) for the conterminous United States"). HUC boundaries do not align with county or place boundaries: against ~3,140 U.S. counties, there are ~20,000 HUC10 watersheds and ~87,000 HUC12 subwatersheds, so a county typically straddles multiple HUC10s and contains many HUC12s. To link county population to watershed water quality you must either (a) aggregate water-quality monitoring sites up to county using their county FIPS attributes (NWIS stores `state_cd`/`county_cd` for each site), or (b) build an **area-weighted crosswalk** that apportions county population to HUC12s by the fraction of each county's area (or, better, populated area) within each watershed. USGS publishes HUC12-based crosswalk tables and the WBD; GIS overlay of TIGER county/place polygons with the WBD is the standard approach. This areal interpolation introduces uncertainty that should be disclosed in any analysis.

### Practical toolchain
For reproducible work, the R **tidycensus** package wraps `get_decennial()`, `get_acs()`, and `get_estimates()`; **tigris** downloads TIGER/Line and cartographic boundary shapefiles directly into R; **rnassqs** wraps the NASS Quick Stats API. Python users can hit the Census API with `requests` and read TIGER cartographic boundary files straight into GeoPandas from the `www2.census.gov` URL.

## Recommendations

**Stage 1 — Pick your population denominator by purpose.**
- Need a clean annual county denominator (2020–present) to normalize runoff/fertilizer per capita? Download PEP CO-EST2025-ALLDATA (CSV) or query the API for older years.
- Need city/municipality totals? Download the PEP SUB-EST file (`sub-est2024.csv` / the V2025 equivalent), filtering SUMLEV = 162 for incorporated places.
- Need exact decennial counts or detailed characteristics for small towns? Use 2020 Census P1 or ACS 5-year B01003 from data.census.gov.

**Stage 2 — Standardize keys.** Immediately cast all FIPS/GEOID fields to zero-padded strings (5 digits for county, 7 for place). For data.census.gov downloads, derive a clean GEOID by stripping the prefix up to "US" from GEO_ID. Keep a documented crosswalk of any place/county boundary or code changes across your time range.

**Stage 3 — Join.** For county-keyed environmental data (USGS fertilizer/manure, NASS Ag Census, ERS, CDC, SAIPE), join directly on the 5-digit county FIPS. For HUC-keyed data (NWIS water quality, ATTAINS), either aggregate sites to county via their county codes or build an area-weighted county↔HUC12 crosswalk using TIGER + the WBD.

**Stage 4 — Build the time series.** Use NHGIS for any analysis spanning multiple decades (it standardizes geography and provides boundary crosswalks). Within a single decade, use one PEP vintage end-to-end; never chain raw counts across decennial boundaries without intercensal estimates.

**Thresholds that change the recommendation:** If your smallest geography is below 65,000 population, drop ACS 1-year in favor of ACS 5-year or PEP/SAIPE. If MOEs on ACS small-area totals exceed ~10–15% of the estimate, switch to PEP (totals) or SAIPE (income/poverty), which have lower variance. If your environmental data is at catchment scale (NHDPlus COMID) rather than HUC12, use the USGS catchment-scale release "Nitrogen and phosphorus inputs from fertilizer and manure in the Continental United States, 2002–2017" (ScienceBase item 65787037d34e952b22746538), which links to NHDPlus v2 via the COMID identifier for 2002, 2007, 2012, and 2017, instead of the county file.

## Caveats
- **Different products, different numbers.** Decennial, PEP, and ACS will not match exactly; report which you used and why.
- **Vintages don't mix.** PEP re-estimates the full series each vintage; combining vintages creates spurious trends.
- **ACS margins of error** at small-area level can be large; always carry and report the MOE.
- **2020 Census privacy noise** affects small-geography counts.
- **Place boundaries are not stable** over time (annexation), unlike counties.
- **County↔watershed misalignment** is the central spatial-join hazard; areal interpolation is approximate.
- **Circularity risk.** USGS nonfarm fertilizer estimates were partly allocated using Census population — the 2017 fertilizer model "uses the same nine variables plus two additional ones: the number of fertilized acres in the county and the population density" (USGS OFR 2020–1153). Using population to "explain" those values can be partly tautological.
- **Series discontinuation.** CDC WONDER bridged-race estimates end with the 2010–2020 intercensal series; NCHS will not produce them going forward.
- **Platform migration.** USGS is decommissioning the legacy NWISWeb interface in favor of Water Data for the Nation (WDFN); some legacy URLs are being redirected, so verify download endpoints at retrieval time.
